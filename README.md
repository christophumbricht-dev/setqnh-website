# setqnh.ch

Website der QNH GmbH. Statisch, Deutsch und Englisch, ohne Tracking.

- **Texte ändern:** in `build.mjs`, danach `node build.mjs`
- **Vorschau:** `node tools/serve.mjs` → <http://localhost:5186/>
- **Online stellen:** GitHub Pages mit der Domain setqnh.ch (gleich wie bei flydownwind.ch)
